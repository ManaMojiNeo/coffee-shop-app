# คู่มือผู้ใช้ - คั่วบ้าน คั่วด้วยใจ

คู่มือสั้นๆ สำหรับสมาชิกทีมใหม่ที่เข้ามาช่วยดูแลร้าน

## สำหรับลูกค้า (ไม่ต้องล็อกอิน)

เปิดหน้าแรกที่ coffee-shop-app-zeta.vercel.app ดูเมนูทั้งหมดได้ที่หน้าเมนู และเสนอเมนูใหม่ที่อยากให้ร้านทำได้ที่หน้าคำขอเมนู ถ้ามีคนขอเมนูเดียวกันแล้วสามารถกดโหวตเพิ่มได้แทนการเพิ่มรายการซ้ำ

## สำหรับเจ้าของร้าน (ต้องล็อกอิน)

ล็อกอินด้วยอีเมลและรหัสผ่านของร้านที่หน้า /login ระบบจะจำการล็อกอินไว้ 7 วันผ่าน cookie หลังล็อกอินแล้วจะเข้าหน้าแดชบอร์ดได้ โดยทำได้ 2 อย่างหลัก

1. บันทึกยอดขาย: เลือกเมนูที่ขายได้ ใส่จำนวน และวิธีชำระเงิน (เงินสด, โอน QR, บัตร) ระบบจะคำนวณยอดรวมให้อัตโนมัติ
2. 2. บันทึกรายจ่าย: ใส่หมวดหมู่รายจ่ายและจำนวนเงิน พร้อมโน้ตเพิ่มเติมได้
  
   3. แดชบอร์ดจะรวมยอดขายและรายจ่ายทั้งหมดให้เห็นภาพรวมของร้านทันที
  
   4. ## ข้อควรระวังสำหรับผู้ใช้งาน
  
   5. ระบบยังไม่ตรวจสอบจำนวนติดลบในช่องยอดขายและรายจ่าย (ดูรายละเอียดในบทที่ 17) ควรตรวจสอบตัวเลขก่อนกดบันทึกทุกครั้ง
